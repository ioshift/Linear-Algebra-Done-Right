# Linear Algebra Reading Notes

Personal reading notes by **Steven Shi**, based on Sheldon Axler’s
*Linear Algebra Done Right*.

- [Note](note.pdf)

## Topics covered

- Vector spaces, subspaces, direct sums, bases and dimension.
- Linear maps, matrices, quotient spaces and duality.
- Polynomials, eigenvalues, invariant subspaces and diagonalization.
- Inner product spaces, orthogonality, minimization and pseudoinverses.
- Self-adjoint and normal operators, the spectral theorem,
  matrix factorizations and singular value decomposition.
- Generalized eigenspaces, nilpotent operators and trace.
- Bilinear and quadratic forms, alternating multilinear forms,
  determinants and tensor products.
